A price chart does not establish causation.

Timing and return differences are observations. This small window has no causal identification, factor model or statistical significance test. SPY helps compare the wider market; it does not remove every competing explanation.

Data, calculations and source files

Indexed price = 100 × adjusted close / the last recorded close before the chosen event. Since-baseline return = indexed price − 100. Minus SPY = asset return − SPY return, in percentage points. One-session return compares consecutive recorded sessions. Adjusted closes reflect the provider’s corporate-action adjustments; they are not raw historical execution prices.

Lines connect daily observations for readability; there is no observation for a weekend or market holiday. US markets were closed on 20 January. The release and 27 January sell-off are separate dates.

How to read this map

Arrows show a possible transmission channel, not a measured causal effect. A source can support a mechanism without proving it explains a particular market move. Challenging a link removes it from this diagram only. Connected nodes are a graph calculation, not a risk score or probability.

Reachability = nodes with an unbroken directed path from the starting event. The map leaves out many real-world influences.
