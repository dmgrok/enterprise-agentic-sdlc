How to read this map

Arrows show a possible transmission channel, not a measured causal effect. A source can support a mechanism without proving it explains a particular market move. Challenging a link removes it from this diagram only. Connected nodes are a graph calculation, not a risk score or probability.

Reachability = nodes with an unbroken directed path from the starting event. The map leaves out many real-world influences.
